### 0-5 DEBUG を環境変数化
- `kataruAI/config/settings.py`：`DEBUG = os.environ.get("DJANGO_DEBUG", "0").lower() in ("1", "true", "yes")`
- 丸山の `.env` にはもともと `DJANGO_DEBUG=1` があった。最初の版は `"True"` という文字列しか受け付けなかったため DEBUG が False になり、静的ファイルが 404 になった → `1`・`true`・`yes` を受け付けるように直した（DEBUG=True・静的ファイル 200 を確認）。
- 各メンバーの `.env` に `DJANGO_DEBUG=1` がなければ追記が必要（ない場合は DEBUG=False になる）。本番の `.env.prod` には書かない（または 0）。
